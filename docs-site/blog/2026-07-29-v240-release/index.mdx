PulseWatch v2.4.0 is focused on public status pages, Telegram notifications, and clearer incident communication.

## What changed

- Public Status Pages
- Telegram notifications
- Incident timeline
- Monitor health overview
- Response time analytics
- Improved dashboard cards
- Faster monitor creation
- Better retry logic
- Reduced API response latency
- Authentication refresh issue fixed
- Public page caching fixed
- Uptime calculation fixed

This release is a meaningful step from a monitor-only tool to a broader incident observability experience.

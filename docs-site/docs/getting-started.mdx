# Getting Started

PulseWatch is a self-hosted uptime monitoring platform with Telegram alerts, AI-explained incidents, and public status pages. Free, forever.

## Quick Start (Hosted)

1. Go to [pulsewatch-monitor.vercel.app](https://pulsewatch-monitor.vercel.app)
2. Sign up with email or **GitHub OAuth**
3. Choose a plan — 14-day free trial of Pro included
4. Add your first monitor — paste any URL
5. Get alerts on Telegram when something goes down

## Self-Host

### Prerequisites

- Python 3.12+, Node.js 18+, PostgreSQL (Neon free tier works)
- Optional: Telegram bot token from [@BotFather](https://t.me/BotFather)

### Backend

```bash
git clone https://github.com/Robibiruk/PulseWatch.git
cd PulseWatch/backend
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # set DATABASE_URL, SECRET_KEY
uvicorn main:app --reload --port 8000
```

### Frontend

```bash
cd frontend && npm install && npm run dev
```

Open `http://localhost:5173`, register, and start monitoring.

## Environment Variables

| Variable | Default | Description |
|:---|:---|:---|
| `DATABASE_URL` | *(required)* | PostgreSQL async URL or SQLite path |
| `SECRET_KEY` | `dev-insecure-change-me` | JWT signing secret |
| `CORS_ORIGINS` | `http://localhost:5173` | Allowed browser origins |
| `TELEGRAM_BOT_TOKEN` | `""` | Bot token from @BotFather |
| `RESEND_API_KEY` | `""` | Resend API key for email alerts |
| `OPENROUTER_API_KEY` | `""` | OpenRouter key for AI explanations |
| `GITHUB_CLIENT_ID` | `""` | GitHub OAuth client ID |
| `GITHUB_CLIENT_SECRET` | `""` | GitHub OAuth client secret |
| `PUBLIC_BASE_URL` | `http://localhost:8000` | Backend URL (for Telegram deep links) |
| `FRONTEND_URL` | `http://localhost:5173` | Frontend URL (for OAuth redirects) |
| `VITE_API_BASE` | `http://localhost:8000` | Backend URL (frontend build-time) |
| `VITE_DOCS_SITE_URL` | `http://localhost:3000` | Docs site URL (frontend build-time) |

## Production Deployment

PulseWatch runs on free-tier infrastructure:

| Service | Host | What it runs |
|:---|:---|:---|
| **API** | Render | FastAPI + worker + Telegram bot |
| **Frontend** | Vercel | React SPA |
| **Docs** | Vercel | Docusaurus |
| **Database** | Neon | PostgreSQL (pooled) |
| **Worker cron** | GitHub Actions | Every 5 min |

The worker uses `SELECT FOR UPDATE SKIP LOCKED` so multiple instances safely share monitors with zero duplicate checks or alerts.

See [Architecture](/docs/architecture) for the full deployment topology.

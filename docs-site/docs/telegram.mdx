# Telegram

PulseWatch includes a Telegram bot for instant notifications and lightweight status commands.

## Connecting Telegram

1. Open `@Pulse_WatchBot`
2. Press `Start`
3. Go to **Settings → Notifications → Connect Telegram**
4. Authorize the bot

Once connected, you will receive downtime, recovery, SSL, heartbeat, and performance alerts directly in Telegram.

## Available Commands

- `/start`
- `/help`
- `/status`
- `/about`

## Notification Types

- Downtime
- Recovery
- SSL expiration
- Heartbeat failure
- Performance warning

# Roadmap

Planned features and improvements.

## Near term

- Multi-region probe support
- Custom domains for status pages
- CLI for monitor management
- Mobile app for incident notifications

## Medium term

- RBAC and team workspaces
- Grafana and datadog integrations
- Richer API assertions and scripting
- Advanced incident routing and escalation

## Long term

- Synthetic browser checks
- Global probe analytics
- Open source client libraries
- Community templates for common stacks

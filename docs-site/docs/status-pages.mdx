# Status Pages

Status Pages let you share service health with the world. Visitors get a live view of uptime, incidents, and scheduled maintenance.

Example status page:

```text
status.pulsewatch.dev/demo
```

Visitors can see:

- Website: `Operational`
- API: `Operational`
- Database: `Operational`

## Customization

- Theme
- Logo
- Description
- Brand color
- Custom domain (`Coming Soon`)

## Maintenance Mode

Display scheduled maintenance without triggering incidents:

```text
Scheduled Maintenance
Expected Duration
2 hours
```

# Glossary

- **Incident** – an unplanned service interruption or degradation detected by PulseWatch
- **Heartbeat** – a periodic inbound signal from an external job to prove it is running on time
- **Monitor** – a configured check for a website, API endpoint, or heartbeat URL
- **Uptime** – the percentage of time a monitor is reporting healthy results
- **Latency** – the measured response time of a successful check
- **Status page** – a public page that shows service health, uptime, and current incidents
